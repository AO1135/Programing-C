# C STEP LAB MAX

GitHub Pages向けのC言語学習アプリです。

## 主な機能
- Lv.0〜Lv.11、合計3,000問（各250問）
- 未回答問題からランダム出題
- 解いた問題は通常モードで再出題しない
- Lv.7〜Lv.11は複数テストケースによる実行結果採点
- 模範解答とコードが違っても、全テストの出力が一致すれば正解
- 間違い復習、模擬試験、学習分析、実績、デイリーミッション
- XP、ランク、コンボ
- JSONバックアップ/復元
- 学習進捗は localStorage のみ。ユーザーの学習記録をサーバーへ保存しません

## コード実行について
Lv.7〜Lv.11の実行結果採点には、ブラウザ上で動作するオープンソースの JSCPP を使用します。JSCPP本体は公開CDN（felixhao28.github.io）から読み込まれます。入力した学習コードを採点用サーバーへ送信する方式ではありません。

JSCPPは教育向けのC/C++インタプリタで、完全なGCC/Clang互換ではありません。stdio/cstdioの一部、基本型、演算、配列、ポインタ、if、switch、for、while、関数などを扱えます。高度なC機能や未対応ライブラリでは、本物のGCC/Clangと挙動が異なる場合があります。

## GitHub Pages
1. ZIPを展開
2. 中身をGitHubリポジトリ直下へアップロード
3. Settings → Pages
4. Deploy from a branch
5. `main` / `/ (root)` を選択して保存

`index.html` がトップページです。
