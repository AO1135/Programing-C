# C STEP LAB

C言語を完全初心者からコード全文作成まで段階的に練習できる、ブラウザ完結型の学習アプリです。

## 特徴
- Lv.0〜Lv.7から好きなレベルを選択
- 選択問題・穴埋め・デバッグ・コード入力
- XP / ランク / 正答率 / 連続正解を表示
- 学習進捗は `localStorage` に端末保存
- サーバー・データベース・ログイン不要
- PC / スマートフォン対応

## GitHub Pagesで公開
1. このフォルダ内の `index.html`、`style.css`、`app.js`、`README.md` をGitHubリポジトリへアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** で **Deploy from a branch** を選びます。
4. Branchを `main`、フォルダを `/ (root)` にして保存します。
5. デプロイ完了後に表示されるURLを共有すれば、ブラウザから利用できます。

## データ保存について
学習記録はブラウザの `localStorage` に保存されます。サーバーへ送信しません。
そのため、別の端末・別のブラウザ・シークレットモードとは進捗が共有されません。ブラウザのサイトデータを削除すると進捗も消えます。

## ファイル構成
- `index.html` : 画面
- `style.css` : デザイン
- `app.js` : 問題、採点、進捗保存
