# C STEP LAB+

C言語を完全初心者からコード全文作成まで練習できる、静的Web学習アプリです。

## 主な機能
- 全8レベル / 2,000問
- 未回答問題からランダム出題（通常モードでは解答済み問題を再出題しない）
- 間違い問題だけの復習モード
- 20問ランダム模擬試験とレベル別結果
- XP / C・B・A・Sランク / コンボ / 正答率
- レベル別正答率分析
- デイリーミッション
- 実績10種
- ヒント
- 学習データのJSONバックアップ / 復元
- PC・スマートフォン対応
- サーバー、DB、ログイン不要

## データ保存
学習データはブラウザの `localStorage` のみに保存します。別端末・別ブラウザには自動同期されません。ブラウザのサイトデータを削除すると進捗も消えるため、必要に応じて「バックアップ」を利用してください。

## GitHub Pages 公開
1. このフォルダ内の `index.html`, `style.css`, `app.js`, `README.md` をGitHubリポジトリのルートへアップロードします。
2. GitHub のリポジトリで **Settings → Pages** を開きます。
3. **Deploy from a branch** を選択します。
4. Branch を `main`、フォルダを `/(root)` にして保存します。
5. 発行されたURLを共有すればブラウザから利用できます。

## 注意
Lv.6〜Lv.7のコード問題は、ブラウザだけで安全に完結させるため、Cコンパイラを実行せず必要キーワード等による簡易採点です。実際のコンパイル結果を使う厳密な自動採点には、別途サーバー側の実行環境/APIが必要です。
